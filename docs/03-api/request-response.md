# Request / Response Examples

All authenticated calls need:

```
Authorization: Bearer <jwt-token>
Content-Type: application/json
```

Tokens are issued at login and expire after **1 day**.

## Login

```
POST /api/auth/login
Body: { "username": "admin", "password": "admin123" }

200:
{
  "token": "eyJ...",
  "user": {
    "id": "uuid",
    "username": "admin",
    "role": "superadmin",
    "first_name": "System",
    "last_name": "Administrator",
    "full_name": "System Administrator",
    "department": "College of Information and Communication Technology (CICT)",
    "course_id": null,
    "course_name": null,
    "system_role": "superadmin"
  }
}
```

Failures:
- Unknown username → `401 { "message": "Invalid username " }` (trailing space is in the source)
- Wrong password → `401 { "message": "Invalid password" }`

Only an existing account's failed attempt is written to the audit log.

## Create Teacher (Admin)

Username is generated by the server — do **not** send it.

```
POST /api/users
Auth: admin
Body:
{
  "first_name": "John",
  "last_name": "Santos",
  "full_name": "John Santos",      // optional; derived from first/last
  "system_role": "teacher",
  "staff_id": "123451234",
  "password": "smartgrade123"
}

201: { "id": "uuid", "full_name": "John Santos", "username": "santos.4512@sg", ... }
```

`department` is inherited from the calling admin. Superadmin must supply `department` when creating an admin.
400 cases: duplicate full name, invalid staff ID, missing fields, admin already exists in the department.

## Create Section

`name` is only the section letter — the server prefixes the course abbreviation and year number.

```
POST /api/sections
Auth: admin
Body:
{
  "name": "A",
  "year_level": "1st",
  "course_id": "uuid",
  "school_year": "2025-2026",
  "semester": "1st Semester"
}

201: { "id": "uuid", "name": "BSIT 1-A", "year_level": "1st", ... }
```

Duplicate → `400 { "message": "A section with this name already exists in this course." }`

## Bulk Save Scores

```
POST /api/component-scores/bulk
Auth: teacher
Body:
{
  "scores": [
    { "activity_id": "uuid", "student_id": "uuid", "score": 85 }
  ]
}
```

Upserts on `(activity_id, student_id)`. Ownership is checked only for the first row.

## Bulk Import Students (from Excel)

```
POST /api/sections/:sectionId/students/bulk
Auth: admin
Body: {
  "students": [
    { "student_id": "26-01234", "first_name": "Juan", "last_name": "Dela Cruz", "mi": "M", "gender": "Male" }
  ]
}

200: {
  "added": 10,
  "skipped": [
    { "student_id": "26-01235", "reason": "Student ID already exists in section" }
  ]
}
```

Duplicates are checked against the section's existing `student_id` values.

## Backup Restore

```
POST /api/backup/restore
Auth: superadmin
Body: {
  "file": { ... },
  "password": "optional",
  "mode": "merge",          // merge | replace | full
  "confirm": "CONFIRM"      // "CONFIRM" for merge/replace, "FULL RESTORE" for full
}
```

Conflicting restore in progress → `409`.

## Error Bodies

Two shapes are in use:

```json
{ "message": "This term is closed. No modifications allowed." }
```

```json
{ "error": "duplicate key value violates unique constraint ..." }
```

`{ message }` is used for validation/permission errors; `{ error }` usually leaks raw database or server messages.

## Status Codes

| Code | Meaning |
|---|---|
| 200 / 201 | Success |
| 400 | Validation or business rule failure (duplicates, missing fields) |
| 401 | No token provided |
| 403 | Invalid token, wrong role, not an owner, or closed term |
| 404 | Missing resource (e.g. no active term) |
| 409 | Restore already running |
| 413 | Backup file/request over 50 MB |
| 500 | Server/database error |
| 502 / 504 | AI provider returned invalid output / timed out |
